Robo Arena

In dem Spiel geht es darum, möglichst viele Monster zu töten, um neue Level und Gegenstände zu bekommen um die Eigenen Atrribute zu verbessern. Währendessen sollte man natürlich bestmöglich nicht sterben, ziel ist es den mittig oben angezeigte Anzahl an Monstern zu töten um das Level ervolgreich abzuschließen.

Steuerung

Ingame:

[W] -> vorwärts / hoch bewegen

[A] -> nach Links bewegen

[S] -> rückwärts / runter bewegen

[D] -> nach Rechts bewegen

[ESC] -> ruft / schließt das Pause / ESC Menü auf

[I] -> ruft / schleißt das Inventar

Inventar:

[RMB] -> auf einem Item rüstet dieses aus / ab

[Drag & Drop] -> verschiebt Items im Inventar

ESC / Settings Menü:

[ESC] -> verlässt das Menü wieder

Setup

Requirements:

Am besten das ganze in einer venv umgebung aufsetzen das variiert je nach System

Die Python Bibliothek pygame

pip install pygame

(optional) die Bibliothek tkinter welche bei der Python installation mitinstalliert werden muss, sollte man selbst Gegenstände Erstellen wollen

Danach folgenden Code ausführen wenn im ROBOARENA Ordner in der richtigen python umgebung

python arenaGame/game.py
